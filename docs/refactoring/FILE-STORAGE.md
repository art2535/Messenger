# File Storage

## Текущее устройство

Файловая подсистема использует контракт `Messenger.Application.Files.IFileStorage` и локальную реализацию `Messenger.Infrastructure.Files.LocalFileStorage`.

- `Uploads` — вложения сообщений; выдаются только через авторизованный API endpoint.
- `Avatars` — публичные аватары; раздаются отдельным static-file middleware.
- `IFileValidationService` проверяет имя, размер, расширение и сигнатуру содержимого. MIME от клиента не считается доверенным.
- Имена новых вложений генерируются сервером и включают ID владельца перед случайной частью имени.
- `UploadOrphanCleanupService` сохраняет ссылки из вложений, аватаров, ожидающих scheduled messages и transactional outbox; удаляет только файлы старше grace period.

## Границы ответственности

- Application содержит контракты хранилища, загрузки и валидации.
- Infrastructure содержит локальную файловую систему и защищает операции от traversal.
- API адаптирует `IFormFile`, проверяет права пользователя и связывает файл с сообщением.
- Вложения не публикуются через общий static-file provider. Публично раздаётся только каталог аватаров.

## Ограничения, принятые для этапа 14

- Только локальное хранилище; S3/MinIO не добавляется.
- Антивирусная проверка и временные ссылки не добавляются.
- Временные файлы и файлы, на которые ещё не ссылается БД/outbox, защищены grace period очистки.
- Старые файлы с прежним форматом имени остаются доступны по существующим attachment records. Проверка префикса владельца применяется к созданию новых attachment records через legacy metadata endpoint.

## Тесты

- `Application/Files/Validation` — политики валидации.
- `Infrastructure/Files/Local` — локальное хранилище, path traversal, лимиты, отмена и изоляция областей.
- `Api/Files/Cleanup` — очистка orphan-файлов и защита ссылок.
- `Api/Files/Upload` — серверная генерация имён и ownership prefix.

Сборка и полный запуск тестов должны быть выполнены в .NET 10 окружении проекта; изменения в этом этапе не считаются прошедшими полный build/test до такого запуска.
